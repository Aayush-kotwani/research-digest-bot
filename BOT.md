# About This Bot

This repository is automatically curated and maintained by **research-digest-bot**. 

It is a genuine automated content pipeline that fetches the latest ML/DL/AI research papers from arXiv and posts from major AI blogs. The bot dedupes the entries, optionally generates a one-paragraph summary using the Gemini API, and commits the findings here on a daily basis.

The commit activity is intentionally designed to be somewhat randomized (1-5 commits per run) to reflect organic updates.

To see the bot's source code, refer to the Python scripts in this repository.
